Use the beta repository for your distribution to receive updates. The Linux beta runs on amd64 and arm64; [Connect](/linux/connect) lists its database engines. There is no stable Linux release yet.

The .deb and .rpm packages need GNOME 50 libraries. Use the PPA on Ubuntu 26.04 or 26.10, COPR on Fedora 44 or 45, and Flatpak on other distributions, including older Ubuntu releases.

## Install the beta

### Ubuntu and Fedora

Add the beta repository, then install `tablepro`:

<CodeGroup>

```bash Ubuntu 26.04 and 26.10
sudo add-apt-repository ppa:tablepro/tablepro-beta
sudo apt install tablepro
```

```bash Fedora 44 and 45
sudo dnf copr enable @tablepro/tablepro-beta
sudo dnf install tablepro
```

</CodeGroup>

apt and dnf install updates, as do Software Updater and GNOME Software.

### Other distributions

Install from the beta Flatpak repository:

```bash
flatpak install --from https://flatpak.tablepro.app/beta-repo/app.tablepro.TablePro.flatpakref
flatpak run --branch=beta app.tablepro.TablePro
```

Opening the [Flatpak install link](https://flatpak.tablepro.app/beta-repo/app.tablepro.TablePro.flatpakref) in a browser starts GNOME Software or KDE Discover. The package uses the GNOME 51 runtime from Flathub. The app itself comes from TablePro's repository, not Flathub.

Run `flatpak update` or use your software center to install updates. If this is your first Flatpak app and the menu does not open it, follow [First Flatpak app](/linux/troubleshooting#first-flatpak-app).

## Install a stable release

Once 0.1.0 is released, add the stable repository:

<CodeGroup>

```bash Ubuntu 26.04 and 26.10
sudo add-apt-repository ppa:tablepro/tablepro
sudo apt install tablepro
```

```bash Fedora 44 and 45
sudo dnf copr enable @tablepro/tablepro
sudo dnf install tablepro
```

</CodeGroup>

With both native repositories enabled, apt and dnf install the highest version: a release replaces its betas, then the next beta replaces that release. To receive only stable releases, disable the beta repository. The installed beta stays until a newer stable version is available.

<CodeGroup>

```bash Ubuntu
sudo add-apt-repository --remove ppa:tablepro/tablepro-beta
```

```bash Fedora
sudo dnf copr disable @tablepro/tablepro-beta
```

</CodeGroup>

Once a stable Flatpak is published, follow the [Flatpak repository instructions](https://github.com/TableProApp/TablePro/blob/main/linux/README.md#flatpak-repository) to install it.

Flatpak installs the beta and stable branches side by side. They share settings and connections, but Flatpak never switches branches by version. Choose which installed branch the app menu starts:

```bash
flatpak make-current app.tablepro.TablePro beta
flatpak make-current app.tablepro.TablePro stable
```

After making the stable branch current, `flatpak uninstall app.tablepro.TablePro//beta` removes the beta. Before moving to an older version, read [After a downgrade](/linux/troubleshooting#after-a-downgrade).

## Packages on GitHub Releases

Download a specific build from [GitHub Releases](https://github.com/TableProApp/TablePro/releases). Linux tags start with `linux-v`, and betas are marked as pre-releases. Subscribe to the [Atom feed](https://github.com/TableProApp/TablePro/releases.atom) for release announcements; it also includes other platforms.

Standalone .deb and .rpm packages need manual updates unless you enable the PPA or COPR. Flatpak bundles receive updates from the corresponding Flatpak repository.

| File | For |
|---|---|
| `tablepro-<version>-ubuntu-<series>-<arch>.deb` | Ubuntu 26.04 or 26.10, `amd64` or `arm64` |
| `tablepro-<version>-fedora-<release>-<arch>.rpm` | Fedora 44 or 45, `x86_64` or `aarch64` |
| `tablepro-<version>-<arch>.flatpak` | Any distribution with Flatpak, `x86_64` or `aarch64` |

Check the download against the release's `SHA256SUMS`, then install the file for your system:

```bash
sha256sum --check --ignore-missing SHA256SUMS
sudo apt install ./tablepro-0.1.0-beta.3-ubuntu-26.04-amd64.deb
sudo dnf install ./tablepro-0.1.0-beta.3-fedora-44-x86_64.rpm
flatpak install ./tablepro-0.1.0-beta.3-x86_64.flatpak
```

Flatpak keeps its files under `~/.var/app/app.tablepro.TablePro/`; [Troubleshooting](/linux/troubleshooting#where-the-files-are) lists them. To build from source, follow the app repository's [Quickstart](https://github.com/TableProApp/TablePro/blob/main/linux/README.md#quickstart).

## Move between native packages and Flatpak

The two formats use different [data folders](/linux/troubleshooting#where-the-files-are) and [secret storage](/linux/troubleshooting#passwords). An empty connection list after switching does not mean the old data was deleted.

<Steps>
  <Step title="Back up saved work">
    Quit the app and [back up its files](/linux/troubleshooting#back-up-saved-work), including query history, saved queries and drafts, before changing formats.
  </Step>
  <Step title="Export connections">
    Reopen the current installation. Choose **Export Connections…** from the main menu and save the file outside its app data folder. Quit it before starting the other installation.
  </Step>
  <Step title="Import in the other installation">
    Install the other format and choose **Import Connections…** from its main menu. Select the exported file and review the import. This transfers connection settings, not history, drafts or passwords.
  </Step>
  <Step title="Sign in again">
    Re-enter database and SSH passwords and key passphrases. Set up cloud AI keys and MCP clients again if you use them. Keep the backup until you have checked your connections and saved work.
  </Step>
</Steps>

## Uninstall

Quit the app first. Package removal keeps your connections, history, drafts, preferences and saved secrets. Use the command for your installation:

<CodeGroup>

```bash Ubuntu
sudo apt remove tablepro
```

```bash Fedora
sudo dnf remove tablepro
```

```bash Flatpak
flatpak uninstall app.tablepro.TablePro
```

</CodeGroup>

For a per-user Flatpak installation, add `--user` to the commands. For a full reset, follow the optional steps next while the app is still installed.

## Optional full reset

Resetting deletes saved work and credentials. [Back up saved work](/linux/troubleshooting#back-up-saved-work) first. The steps affect this desktop account, not your server databases or SQLite and DuckDB files stored elsewhere.

<Steps>
  <Step title="Reset preferences before uninstalling">
    Quit the app. Reset GSettings while the installed package still provides its schema:

    <CodeGroup>
    ```bash Native package
    gsettings reset-recursively app.tablepro.TablePro
    ```
    ```bash Flatpak
    flatpak run --command=gsettings app.tablepro.TablePro reset-recursively app.tablepro.TablePro
    ```
    </CodeGroup>
  </Step>
  <Step title="Remove saved work and secrets">
    For native packages, remove these folders. The commands respect custom XDG locations and delete connections, history, saved queries, tabs, drafts, snippets and crash reports:

    ```bash
    rm -rf -- "${XDG_CONFIG_HOME:-$HOME/.config}/tablepro" \
      "${XDG_STATE_HOME:-$HOME/.local/state}/tablepro" \
      "${XDG_DATA_HOME:-$HOME/.local/share}/tablepro" \
      "${XDG_CACHE_HOME:-$HOME/.cache}/tablepro"
    ```

    In Passwords and Keys (Seahorse) or KWallet Manager, delete only the [TablePro secret entries](/linux/troubleshooting#saved-secret-entries). Removing the folders does not remove those keyring items. Then remove the native package with the uninstall command.

    For Flatpak, use this instead of the keep-data uninstall command:

    ```bash
    flatpak uninstall --delete-data app.tablepro.TablePro
    ```

    [The delete-data option](https://docs.flatpak.org/en/latest/flatpak-command-reference.html#flatpak-uninstall) removes the sandbox's data and permissions, including its encrypted secret file. If the desktop keyring still lists a Secret portal item for this app, remove that item too. Native-installation keyring entries remain separate.
  </Step>
  <Step title="Remove repository configuration if no longer needed">
    For native packages, remove both repositories if you enabled both:

    <CodeGroup>
    ```bash Ubuntu
    sudo add-apt-repository --remove ppa:tablepro/tablepro-beta
    sudo add-apt-repository --remove ppa:tablepro/tablepro
    ```
    ```bash Fedora
    sudo dnf copr remove @tablepro/tablepro-beta
    sudo dnf copr remove @tablepro/tablepro
    ```
    </CodeGroup>

    For Flatpak, run `flatpak remotes`. Remove an unused TablePro remote with `flatpak remote-delete REPOSITORY`, replacing `REPOSITORY` with its listed name. Keep Flathub if other apps or runtimes use it.
  </Step>
</Steps>
