---
title: Keyboard shortcuts
description: Every key the Linux app binds, by where the focus is
tag: "Beta"
---

`Ctrl+?` opens the same list inside the app, as does **Keyboard Shortcuts** in the main menu. The keys are fixed; none can be rebound yet.

Focus decides what some keys do. `Ctrl+F` searches the connection list, filters a table tab, finds in query results or finds in the editor, by where the focus is. `Escape` closes a dialog, stops a running query, or drops a selection or extra cursors.

## General

| Action | Shortcut |
|---|---|
| New window | `Ctrl+Shift+N` |
| Preferences | `Ctrl+,` |
| Search connections | `Ctrl+F` |
| Query history | `Ctrl+Shift+H` |
| Export the active tab's results or rows | `Ctrl+Shift+E` |
| Show or hide the sidebar | `F9` |
| Show or hide the assistant | `Ctrl+Alt+A` |
| Keyboard shortcuts | `Ctrl+?` |
| Close a dialog | `Escape` |
| Quit | `Ctrl+Q` |

## Tabs

| Action | Shortcut |
|---|---|
| New SQL editor tab | `Ctrl+T` |
| Close the tab, or an empty window | `Ctrl+W` |
| Reopen the last closed tab | `Ctrl+Shift+T` |
| Switch to the recent tab. Hold `Ctrl` and press `E` again to go further back | `Ctrl+E` |
| View open tabs | `Ctrl+Shift+O` |
| Next tab | `Ctrl+Tab` or `Ctrl+Page Down` |
| Previous tab | `Ctrl+Shift+Tab` or `Ctrl+Page Up` |
| Move the tab right | `Ctrl+Shift+Page Down` |
| Move the tab left | `Ctrl+Shift+Page Up` |

| Select all rows | `Ctrl+A` |
