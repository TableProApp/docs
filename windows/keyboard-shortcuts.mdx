---
title: Keyboard shortcuts
description: Every key TablePro for Windows binds, by where the focus is
---

The menus show each command's key beside it, and `Alt` with a menu's underlined letter opens it. The keys are fixed; none can be rebound yet.

Focus decides what some keys do. `F2` renames a query tab when the tab has focus, edits a cell in the grid, and renames a row on the Connections page. `Ctrl+S` saves a table's pending changes in a table tab and the file in a query tab.

## General

| Action | Shortcut |
|---|---|
| New connection | `Ctrl+N` |
| Open a database or SQL file | `Ctrl+O` |
| Connections page | `Ctrl+Shift+H` |
| Show or hide the object tree | `Ctrl+B` |
| Filter objects | `Ctrl+P` |
| Switch database | `Ctrl+K` |
| Refresh the object tree | `F5` |
| Export results | `Ctrl+Shift+E` |
| Documentation | `F1` |

## Tabs

| Action | Shortcut |
|---|---|
| New query tab | `Ctrl+T` |
| Close the tab | `Ctrl+W` or `Ctrl+F4` |
| Reopen the last closed tab | `Ctrl+Shift+T` |
| Next tab, previous tab | `Ctrl+Tab`, `Ctrl+Shift+Tab` |
| Tab 1 to 8, the last tab | `Ctrl+1` to `Ctrl+8`, `Ctrl+9` |
| Rename the query tab | `F2` |

## Query tab

| Action | Shortcut |
|---|---|
| Run the selection, or the whole text | `Ctrl+Enter` |
| Run the statement at the cursor | `Ctrl+Shift+Enter` |
| Stop | `Shift+F5` |
| Save the file, save it as | `Ctrl+S`, `Ctrl+Shift+S` |
| Find, Find and replace | `Ctrl+F`, `Ctrl+H` |
| Next match, previous match | `F3`, `Shift+F3` |
| Replace all, in the find bar | `Ctrl+Alt+Enter` |
| Close the find bar | `Escape` |
| Comment or uncomment lines | `Ctrl+/` |
| Fold, unfold | `Ctrl+Shift+[`, `Ctrl+Shift+]` |
| Move lines up or down | `Alt+Up`, `Alt+Down` |
| Copy lines up or down | `Shift+Alt+Up`, `Shift+Alt+Down` |
| Delete lines | `Ctrl+Shift+K` |
| Select the next match of the word | `Ctrl+D` |
| Add a cursor above or under | `Ctrl+Alt+Up`, `Ctrl+Alt+Down` |
| Zoom in, out, back | `Ctrl+=`, `Ctrl+-`, `Ctrl+0` |
| Undo, redo | `Ctrl+Z`, `Ctrl+Y` |

In [Vim mode](/windows/sql-editor#vim-mode), Normal mode takes `Ctrl+A`, `Ctrl+B`, `Ctrl+D`, `Ctrl+F` and `Ctrl+P` for Vim's own commands.

## Table tab

| Action | Shortcut |
|---|---|
| Show or hide the filter bar | `Ctrl+Shift+F` |
| Apply the filter | `Enter` in a value box |
| Edit the focused cell | `F2`, `Enter` or a double-click |
| Keep the edit | `Enter`, or `Ctrl+Enter` in a value with line breaks |
| Keep it and move to the next or previous cell | `Tab`, `Shift+Tab` |
| Cancel the edit | `Escape` |
| Add a row | `Ctrl+Shift+N` |
| Duplicate the selected rows | `Ctrl+Shift+D` |
| Mark the selected rows for deletion | `Delete` |
| Save changes | `Ctrl+S` |
| Preview SQL | `Ctrl+Shift+P` |
| Move the column left or right | `Alt+Left`, `Alt+Right` |
| Copy the selected cells | `Ctrl+C` |

## Connections page

| Action | Shortcut |
|---|---|
| Connect | `Enter` |
| Rename | `F2` |
| Delete, after asking | `Delete` |
| New connection from a URL on the clipboard | `Ctrl+V` |
| Leave selection mode, or keep the old name while renaming | `Escape` |
