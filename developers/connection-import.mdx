---
title: Connection Import
description: Every query parameter a tablepro://import link accepts, and which ones the app refuses
---

An import link opens a review sheet before saving a connection. It carries connection settings,
not passwords or approval to use local credentials.

```text
tablepro://import?name=Staging&host=db.example.com&port=5432&type=postgresql&username=admin
```

`name`, `host` and `type` are required. `socket` can stand in for `host`. `type` takes any registered database type name,
case-insensitive: `MySQL`, `PostgreSQL`, `MongoDB`, `Redis`, `ClickHouse`, `Oracle`, `DuckDB`,
`Cassandra`, and every other type a loaded plugin registers.

Enum-valued parameters must match a listed value exactly, since these are stored raw values rather
than display names, and an unrecognized one falls back rather than failing the link. Percent-encode
values that contain spaces: `sslMode=Verify%20CA`.

## Core parameters

| Parameter | Description |
|-----------|-------------|
| `port` | Server port. Defaults to the type's standard port. |
| `socket` | MySQL and MariaDB take a socket file path. PostgreSQL takes its folder and keeps `port`. See [Socket](#socket). |
| `username` | Database username. |
| `database` | Default database name. |
| `color` | Sidebar color: `Red`, `Orange`, `Yellow`, `Green`, `Blue`, `Purple`, `Pink`, `Gray` or `None`. Falls back to `None`. |
| `icon` | SF Symbol name to draw instead of the type's icon, such as `server.rack`. Lowercase letters, digits and dots, up to 100 characters; anything else is dropped. A name this macOS lacks is kept and draws the type's icon. |
| `tagName` | Tag to assign. Repeat the parameter for more than one tag. |
| `groupName` | Group to place the connection in. Repeat the parameter for a nested group, outermost first. |
| `safeModeLevel` | `silent`, `alert`, `alertFull`, `safeMode`, `safeModeFull` or `readOnly`. Falls back to `silent`. |
| `aiPolicy` | `alwaysAllow`, `askEachTime` or `never`. Falls back to the app default. |
| `redisDatabase` | Redis database index to select on connect. |
| `startupCommands` | SQL to run after connecting. The review sheet shows it in full. |
| `connectTimeoutSeconds` | Seconds to wait for the connection, `1` to `600`. Out of range falls back to the app default. |
| `queryTimeoutSeconds` | Seconds a query may run before it is canceled, `0` to `2147483`. `0` turns the limit off. Out of range falls back to the app default. |
| `localOnly` | `1` keeps the connection off iCloud sync. |

### Socket

- `host` becomes optional and defaults to `localhost`.
- Other types and `ssh=1` ignore `socket`.
- The path must start with `/` and fit in 103 bytes.
- A path with a control or invisible character refuses the link.
- `af_localSocketPath` is read the same way.

## SSH parameters

Set `ssh=1`, or none of these are read.

| Parameter | Description |
|-----------|-------------|
| `sshHost` | SSH server hostname. |
| `sshPort` | SSH port. Default `22`. |
| `sshUsername` | SSH username. |
| `sshAuthMethod` | `Password`, `Private Key`, `SSH Agent`, `Keyboard Interactive` or `None`. Falls back to `Password`. |
| `sshPrivateKeyPath` | Path to the private key file. |
| `sshAgentSocketPath` | Custom SSH agent socket path. |
| `sshJumpHosts` | JSON array of `{host, port, username, authMethod, privateKeyPath}`. Jump `authMethod` is `Private Key` or `SSH Agent`, falling back to `SSH Agent`. |
| `sshTotpMode` | `none`, `auto_generate` or `prompt_at_connect`. Falls back to `none`. |
| `sshTotpAlgorithm` | `SHA1`, `SHA256` or `SHA512`. Default `SHA1`. |
| `sshTotpDigits` | Code length. Default `6`. |
| `sshTotpPeriod` | Period in seconds. Default `30`. |

## SSL parameters

| Parameter | Description |
|-----------|-------------|
| `sslMode` | `Disabled`, `Preferred`, `Required`, `Verify CA` or `Verify Identity`. Falls back to `Required`, and the review sheet says so. |
| `sslCaCertPath` | CA certificate file path. |
| `sslClientCertPath` | Client certificate file path. |
| `sslClientKeyPath` | Client key file path. |

## Driver fields

Use `af_<fieldId>` for a known driver field. For example, `af_mongoReplicaSet=myrs` sets
`mongoReplicaSet` on a MongoDB connection. Match the field ID's case exactly.

Known settings, destination fields and local file paths are accepted. Unknown fields are dropped.
A sign-in selector that uses local credentials is also dropped: examples include
`af_mssqlAuthMethod=windows`, `af_awsAuth=profile`, and `af_usePgpass=true`.
A plain selector such as `af_mssqlAuthMethod=sql` is kept.

Secrets, internal fields and local script settings are refused under the same
[field rules as a file import](/features/connection-sharing#import). Configure those settings in
the connection editor. Imported connections do not carry
[sign-in approval](/connections/connection-form#sign-ins-from-this-mac).

## What the user sees

The review sheet shows the type, host and port or socket, database, username, SSH auth method, SSL mode, color,
icon, tags, group path, driver fields, and startup SQL. Only the name is editable. **Add Connection**
saves it; when a connection to the same host, port, socket, database and username is already saved, the sheet
warns *"A connection to this server is already saved as “…”."* and the button becomes
**Add as Copy**.

The saved connection has no password, so open it in the connection editor and add one before
connecting.
