Use the [macOS command](/integrations/terminal) or [Linux command](/linux/command-line) for shell scripts. Use an MCP client for an AI assistant, or a link to open a connection in the app.

<CardGroup cols={2}>
  <Card title="MCP clients" icon="robot" href="/integrations/mcp-clients">
    Connect Claude, Cursor, VS Code, Zed and other MCP clients.
  </Card>
  <Card title="Raycast" icon="magnifying-glass" href="/integrations/raycast">
    Search connections, browse schemas and run SQL from Raycast.
  </Card>
  <Card title="Terminal" icon="terminal" href="/integrations/terminal">
    Install the macOS command and run queries, browse connections or export tables.
  </Card>
  <Card title="DDEV" icon="cube" href="/integrations/ddev">
    Open a project's database with `ddev tablepro`.
  </Card>
  <Card title="Shortcuts" icon="wand-magic-sparkles" href="/integrations/shortcuts">
    Run a query, add rows or open a connection from Shortcuts on a Mac, iPhone or iPad.
  </Card>
</CardGroup>

**Help > Integrations** opens the full directory, community integrations included, at [tablepro.app/integrations](https://tablepro.app/integrations).

To build an integration of your own, start at [Developers](/developers).
