## Themes

A theme colors what a window shows: the SQL editor and the other code views, the data grid, value viewers and inspector fields, JSON and PHP trees, diffs, ER diagrams, query plans and charts. Its window background fills the space behind them. On macOS 26 and later the sidebar, inspector and toolbar take on that background through the system glass, while controls and Settings keep the system look. The welcome window, the connection form and sheets keep it too, but a code field inside one, such as **Startup Commands**, **Pre-Connect Script** or a favorite's query, takes the editor colors.

With Increase Contrast on, the window background goes back to the macOS color and the rest of the theme stays.

Default Light and Default Dark draw the editor and the grid in the macOS colors, so selection, the cursor, the current line and the focus ring follow your Accent and Highlight colors in System Settings > Appearance, and Increase Contrast. Their syntax colors are Xcode's defaults, and switch to Xcode's high-contrast palette when Increase Contrast is on. Dracula and Nord ship as dark themes.

A theme only appears in the picker for its own appearance. If the theme a picker holds is missing on this Mac, for example one chosen on another Mac, the picker shows the theme in use and says why.

## Custom themes

Custom themes are listed under **Custom Themes**.

| Control | What it does |
|--------|--------|
| **+** menu | **New Theme Based On** copies any theme, built-in ones included; **Import…** reads a theme JSON file |
| **-** button | Deletes the selected theme after you confirm. A picker that held it goes back to Default Light or Default Dark |
| **...** menu | **Edit…**, **Rename…**, **Duplicate**, **Export…** and **Show in Finder** for the selected theme |

Double-click a theme or press Return to edit it, and press Delete to delete it. The same actions are in its right-click menu.

**Edit…** opens a sheet with a live preview, the theme's name and a color well for each color. A color you have not set draws in the macOS color shown in its well; once you set one, the arrow beside it puts the default back. Changes save as you make them.

| Group | Colors |
|-------|----------|
| Window | Background |
| Editor | Background, text, cursor, selection, current line, current statement, line number, invisibles |
| Syntax | Keyword, string, number, comment, NULL, operator, function, type |
| Data Grid | Background, text, alternate row, header background, header text, grid line, selection, selected text, inactive selection, focus border, NULL value, bool true and false, row number, modified, inserted and deleted rows, deleted text |

A theme file that cannot be read is listed under **Not Loaded** with the reason. Right-click it and choose **Show in Finder** to fix or remove the file.

Fonts are not part of a theme. Editor Font lives in [Editor settings](/customization/editor-settings) and Data Grid Font in [Data settings](/customization/data-settings), and both stay on the Mac you set them on.

## Theme files

A theme is one JSON file in `~/Library/Application Support/TablePro/Themes/`. **Export…** writes the colors the selected theme sets, which is the shortest way to start one.

| Key | Holds |
|-----|-------|
| `schema` | Format version. `3` is the version this release reads |
| `id`, `name`, `author` | Identity. An `id` that collides with a built-in theme or one you already have is replaced on import |
| `appearance` | `light` or `dark`. Decides which picker lists the theme |
| `window` | Window background, under `background` |
| `editor` | Editor colors, with syntax colors nested under `syntax` |
| `dataGrid` | Data grid colors |

```json
{
  "schema": 3,
  "id": "user.midnight",
  "name": "Midnight",
  "author": "You",
  "appearance": "dark",
  "window": { "background": "#242933" },
  "editor": {
    "background": "#2E3440",
    "text": "#D8DEE9",
    "syntax": { "keyword": "#81A1C1", "string": "#A3BE8C" }
  },
  "dataGrid": { "background": "#2E3440", "selection": "#434C5E" }
}
```

A color is sRGB hex, `#RRGGBB`, or `#RRGGBBAA` for a translucent band such as a selection. Every color is optional. One you leave out draws in the macOS color for that spot, and a syntax color you leave out takes the Default Light or Default Dark value.

A file that names a color TablePro does not use, sets one twice, carries a color the app cannot parse, or declares a `schema` this release does not read is listed under **Not Loaded** with the reason. Themes written for earlier versions of TablePro need to be written again.

## Connection colors

Assign one with **Color** on the connection form's **Appearance** tab: None, Red, Orange, Yellow, Green, Blue, Purple, Pink, or Gray. With None, no color cue appears. Connection groups take a color the same way, from their right-click menu on the welcome window.

In the workspace rail the color is a dot on the corner of the database icon, and it stays visible on the selected row. In the welcome window list, the connection switcher and the query history drawer, it is a dot beside the name. The color's name is in the connection's tooltip and its VoiceOver label.

The database icon keeps its engine's own color everywhere, whichever color the connection carries.

<Tip>
Use red for production databases as a visual reminder to be careful with queries.
</Tip>
