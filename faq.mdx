## Cost and plans

<AccordionGroup>

<Accordion title="Is TablePro free?">
Yes, with no account and no trial countdown. A paid plan adds the features in the plan table and changes nothing else. See [Licensing](/features/licensing).
</Accordion>

<Accordion title="What does a paid plan add?">
Two paid plans. Pro covers iCloud Sync, encrypted connection export, environment variables in connection fields, Linked Folders, Query Insights, result charts, Compare & Sync, Data Rewind, and shared links past the Free limits. Team adds the Team Catalog and the Team Library on top of Pro. Sign in to a TablePro account to use them, on up to 3 devices. [Licensing](/features/licensing) lists prices and shows what each feature does without a plan.
</Accordion>

<Accordion title="Can I use it at work?">
Yes, free or paid. To share connections and saved queries with teammates, a Team plan hands out seats from your account at account.tablepro.app: each teammate accepts an emailed invitation and signs in with an account of their own. See [Teams](/features/team).
</Accordion>

<Accordion title="What license is the source code under?">
The GNU Affero General Public License v3.0, plugins included. A TablePro plan is a separate thing: it unlocks the paid features, not the app.
</Accordion>

</AccordionGroup>

## Privacy and security

<AccordionGroup>

<Accordion title="Is my data sent anywhere?">
Ordinary queries and results go to your database. Mac usage data is on by default and, from 0.86.0, goes directly to PostHog with installation or account identifiers. Turn off **Share usage data** in **Settings > General > Privacy**. [Privacy](/security/privacy#usage-data) lists events, fields and older-version behavior. AI providers and MCP clients receive authorized context and tool results. Publishing to Team Library or sending content to support shares that content too.
</Accordion>

<Accordion title="Is my password safe?">
Passwords go into the macOS Keychain, not the connections file. An ordinary export leaves them out, the Team Library carries the connection definition and query text only, and MCP clients query through your saved connections without seeing one. Two exceptions: **Copy Connection String** puts the password on the clipboard in plain text, marked concealed so clipboard history apps that honor the marker skip it, and an encrypted export (Pro) carries credentials behind a passphrase. See [Connection Sharing](/features/connection-sharing).
</Accordion>

<Accordion title="Where does my data live on disk?">
Under `~/Library/Application Support/TablePro`: connection definitions without their passwords, query history, saved queries, open tabs, per-table filters, and any plugin you installed. Preferences are in `~/Library/Preferences/com.TablePro.plist`. [Privacy](/security/privacy) names every file and what it holds.
</Accordion>

<Accordion title="How do I remove it completely?">
Drag the app to the Trash, then delete the Application Support folder and the preferences file. Keychain items and anything already synced to iCloud have to go separately. [Installation](/installation) has the commands.
</Accordion>

</AccordionGroup>

## Databases and drivers

<AccordionGroup>

<Accordion title="Which databases are supported?">
[Supported Databases](/databases) lists every engine with its default port. [Managing Connections](/connections) adds the transport each supports and whether it can go through an SSH tunnel, SSL, Cloudflare Tunnel, Cloud SQL Proxy, or a SOCKS proxy.
</Accordion>

<Accordion title="Why is my database not in the list?">
Its driver is probably not installed yet. The database type chooser badges registry drivers **Not Installed**; pick one anyway and the download runs before the connection opens, with no restart. See [Plugins](/features/plugins).
</Accordion>

<Accordion title="Why does a driver need downloading?">
<DriverCounts />

Each one must match the SHA-256 checksum in the registry manifest and carry a valid code signature before it loads.
</Accordion>

<Accordion title="Why does a plugin need updating after I update the app?">
An app update can raise the plugin interface version, and a plugin built against the old one is rejected at load rather than crashing. TablePro repairs it at the next launch by reinstalling a compatible build from the registry. Until then the plugin sits in a banner in **Settings > Extensions** with the reason and an action.
</Accordion>

</AccordionGroup>

## Platforms and sync

<AccordionGroup>

<Accordion title="Does it work offline?">
Connecting, browsing, and querying need nothing but the database. What does need the network: installing or updating a plugin, and any AI provider that is not local. A paid plan keeps working offline for up to 14 days after its last check, and a Mac that never goes online imports an offline file instead. See [Licensing](/features/licensing#validation-and-offline-use).
</Accordion>

<Accordion title="Does it sync between Macs?">
Through iCloud or TablePro Sync, with a paid plan; pick one under **Settings > Sync**, which starts off. Each category has its own toggle, passwords included, and a connection can be marked **Local Only** to stay on one Mac. [Sync](/features/sync) lists what TablePro Sync carries, and [iCloud Sync](/features/icloud-sync) what iCloud carries.
</Accordion>

<Accordion title="Is there an iPhone app?">
Yes. The stable iPhone and iPad app needs no account or plan. See [iPhone and iPad](/ios) for requirements, connections, queries, and sync.
</Accordion>

<Accordion title="Is there a Linux version?">
Yes. The public beta has its own [supported engines](/linux/connect#engines). [Install on Linux](/linux/install) covers the beta PPA, COPR, Flatpak repository, and release packages. [Licensing](/features/licensing) links to Linux account details.
</Accordion>

<Accordion title="Is there a Windows version?">
The Windows app is in development and has no release yet. Follow progress in the [Windows source directory](https://github.com/TableProApp/TablePro/tree/main/windows).
</Accordion>

<Accordion title="How often does TablePro release, and will it keep interrupting me?">
Releases go out when the work is ready, which lately averages one every three days. They should not interrupt you: a new version downloads in the background and installs the next time you quit, with no dialog.

The one exception is a fix you need straight away, meaning data loss, a crash on a common path, or a security issue. Those are flagged so they surface immediately.

**Settings > General > Software Update** turns automatic installs off so you are asked each time, or turns checks off entirely. An administrator can pin both, and the check interval, for a fleet: see [Managed updates](/security/managed-updates).
</Accordion>

</AccordionGroup>

## Moving from another client

<AccordionGroup>

<Accordion title="How do I move from TablePlus?">
**File > Import > Import from Other App…** reads the connections TablePlus already has, groups included, and TablePlus does not need to be running. Passwords come along once you select **Include passwords**. Each is its own Keychain item, so macOS asks per item; choose **Always Allow** and it stops asking. Saved queries come across too, into a folder named TablePlus that every connection shows. Query history and column widths do not. For TablePlus's keys, choose it under **Use Shortcuts From** in **Settings > Keyboard**. The same dialog handles Sequel Ace, DBeaver, DataGrip, Beekeeper Studio, and Navicat. See [Switching to TablePro](/switching).
</Accordion>

<Accordion title="What if my client is not in the importer?">
Two other routes. **File > Import > Import from URL…** takes a `postgres://` or `mysql://` URL and fills in the form. [Open Project Folder](/features/project-folder-import) reads database settings out of a repository's `.env`, `docker-compose.yml`, or framework config, so a project becomes a connection without typing a host.
</Accordion>

</AccordionGroup>
